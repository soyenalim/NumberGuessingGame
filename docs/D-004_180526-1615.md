> Max distance varies by target position
>> Target at 50: max distance = 50. Freezing (53+) is **impossible**.
>> Target at 0 or 100: max distance = 100. Freezing (51–100) is **possible**.

> This means Freezing is a rare "edge-target" state — a genuine *you're completely lost* signal that only appears when the target sits at the extreme. For middle targets, Cold (16–50) is the "worst" feedback.
